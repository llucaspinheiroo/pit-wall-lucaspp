# PIT WALL – GP de São Paulo

## Descrição do projeto

Este projeto foi desenvolvido como parte da atividade de Linguagem de Marcação (LIMA), com o objetivo de recriar a página do GP de São Paulo de Fórmula 1, utilizando HTML e CSS.

A página apresenta informações sobre os pilotos, classificação, equipes e ingressos para o evento, seguindo o modelo visual disponibilizado pelo professor.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts (Titillium Web)

## Estrutura do projeto

```text
pit-wall/
├── index.html
├── styles.css
└── img/
    └── piloto.jpg
```

## Recursos utilizados

- Estruturação com tags semânticas HTML.
- Variáveis CSS utilizando `:root` e `var()`.
- Flexbox para organização dos elementos.
- Grid com `auto-fit` para os cards dos pilotos.
- Tabela HTML com `thead` e `tbody` para a classificação.
- Formulário de ingressos com campos organizados em duas colunas.
- Efeitos `hover` nos elementos.
- Gradientes e imagem de fundo.
- Faixa decorativa simulando a zebra da pista.
- Responsividade utilizando `@media` para dispositivos móveis.

## Responsividade

A página foi adaptada para funcionar em computadores e celulares, reorganizando os elementos para melhorar a visualização em telas menores.

## Observação

O projeto é exclusivamente de front-end. Os botões e o formulário possuem comportamento visual e navegação entre as seções, sem integração com banco de dados ou sistema de reservas.
